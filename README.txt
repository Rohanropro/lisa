# AgriNepal — Crop Production & Environmental Analysis

## Run it in under 2 minutes
1. Extract the ZIP.
2. Open the `nepal_crop_dashboard` folder in VS Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.
4. Internet access is required for Google Fonts and Chart.js CDN charts.

## Included
- Dashboard with interactive demo charts and filters
- Regional comparison page
- Environmental analysis page
- Yield calculator (derived yield, not a trained prediction model)
- Demo data-management page with add/remove and CSV export
- Administrator prototype page
- Responsive layout for desktop/mobile

## Important limitations
This is a frontend prototype. The displayed figures are illustrative sample data, not official Nepal statistics. Records added/removed are kept only in browser memory for the current session. No Python backend, MySQL connection, real authentication, or server-side authorization is included. Do not use real personal or confidential data.

## Next step for a connected system
Create a Python backend API, connect it to the existing MySQL schema, replace demo arrays with API requests, and implement authentication and authorization on the server.
